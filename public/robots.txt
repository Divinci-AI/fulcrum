# Fulcrum robots policy.
#
# OG / link-unfurl paths (/og/*, /tasks/*, /projects/*, /repositories/*,
# /apps) are intentionally publicly readable so Slack/Discord/iMessage
# crawlers can render unfurls when a tenant URL is shared. The privacy
# model is UUID-gated: holding the URL implies authorized to see the
# OG metadata (title, status, project, priority, due, assignee, 140-char
# description preview).
#
# Search engines and archive bots SHOULD NOT index these URLs — if a
# URL leaked into a public space (a public Slack channel that gets
# indexed, a Twitter post, a blog), the metadata would otherwise show
# up in search results. Slack/Discord/etc. ignore robots.txt because
# they're link-preview crawlers (per spec), not search-index crawlers,
# so this rule doesn't break unfurls.
